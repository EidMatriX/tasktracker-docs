# Добро пожаловать в TaskTracker

**TaskTracker** — это веб-приложение для командной работы над задачами: планирование спринтов, назначение исполнителей, отслеживание статусов и интеграция с внешними системами через REST API.

| [Для разработчиков](dev/setup.md) | Локальный запуск и участие в разработке |

## Возможности системы

- **Проекты и доски** — несколько проектов в одной организации, канбан-доски и списки.
- **Задачи** — заголовок, описание в Markdown, приоритет, сроки, метки и вложения.
- **Роли** — владелец организации, администратор проекта, участник и наблюдатель с разными правами.
- **Уведомления** — e-mail и in-app при назначении, упоминаниях и смене статуса.
- **API** — версионированный REST API с аутентификацией по токенам и ограничением частоты запросов.

## Термины

- **Организация** — верхний уровень изоляции данных (компания или команда).
- **Проект** — контейнер задач с настраиваемыми колонками и правилами workflow.
- **Задача** — единица работы с уникальным идентификатором внутри проекта (например, `PROJ-42`).

!!! tip "С чего начать"
    Если вы впервые открыли TaskTracker, откройте раздел [Быстрый старт](user-guide/quick-start.md) — там пошагово описаны регистрация, создание проекта и первой задачи.

## Обратная связь

Вопросы по документации и предложения по улучшению можно направлять через тикет-трекер проекта или на адрес поддержки, указанный в настройках вашей организации.
