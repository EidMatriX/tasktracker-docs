# Обзор API

REST API TaskTracker предназначен для интеграции с CI/CD, ботами, внутренними порталами и скриптами миграции данных. Все запросы выполняются по HTTPS; ответы — в формате JSON с кодировкой UTF-8.

## Базовый URL и версия

```text
https://api.tasktracker.example.com/v1
```

Префикс `/v1` фиксирует контракт: при несовместимых изменениях будет выпущена новая версия (`/v2`), а `/v1` сохранится на период поддержки.

## Аутентификация

Используются **личные токены доступа** (Personal Access Token, PAT).

Заголовок запроса:

```http
Authorization: Bearer <YOUR_TOKEN>
```

Токен создаётся в интерфейсе: **Профиль** → **Безопасность** → **Токены API**. Храните токен в секретах (переменные окружения, vault), не коммитьте в репозиторий.

!!! warning "Срок действия и отзыв"
    Токен можно ограничить по сроку и отозвать в любой момент. После отзыва запросы с этим токеном возвращают `401 Unauthorized`.

## Идемпотентность

Для операций создания и изменения поддерживается заголовок:

```http
Idempotency-Key: <уникальный-uuid-или-строка>
```

Повтор запроса с тем же ключом и телом в течение окна 24 часов возвращает тот же результат без дублирования сущностей.

## Ошибки

Тело ошибки в общем виде:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Поле title обязательно",
    "details": [
      { "field": "title", "issue": "required" }
    ]
  }
}
```

Частые HTTP-коды:

| Код | Значение |
|-----|----------|
| 400 | Неверные параметры или тело запроса |
| 401 | Отсутствует или недействителен токен |
| 403 | Недостаточно прав для ресурса |
| 404 | Ресурс не найден |
| 409 | Конфликт (например, дубликат ключа) |
| 429 | Превышен лимит запросов |
| 500 | Внутренняя ошибка сервера |

## Лимиты запросов

По умолчанию: **1000 запросов в час** на токен, **100 запросов в минуту** с одного IP. Заголовки ответа:

```http
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 847
X-RateLimit-Reset: 1712739600
```

При исчерпании лимита возвращается `429` и заголовок `Retry-After` в секундах.

## Основные группы endpoint'ов

| Группа | Назначение |
|--------|------------|
| `/organizations`, `/projects` | Организации и проекты |
| `/tasks` | Создание, чтение, обновление задач |
| `/users`, `/memberships` | Пользователи и членство в организациях |

Детальное описание операций над задачами: [Задачи — endpoints](endpoints/tasks.md).

## Пагинация списков

Списковые endpoint'ы принимают параметры:

- `page` — номер страницы, начиная с `1`;
- `per_page` — размер страницы (по умолчанию 20, максимум 100).

Ответ включает метаданные:

```json
{
  "data": [ ... ],
  "meta": {
    "page": 1,
    "per_page": 20,
    "total_count": 156,
    "total_pages": 8
  }
}
```

!!! tip "Стабильная сортировка"
    Для длинных выгрузок комбинируйте пагинацию с параметром `sort=updated_at` и при необходимости фильтруйте по `updated_after` для инкрементальной синхронизации.
