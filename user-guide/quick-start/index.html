    Быстрый старт

    Этот раздел поможет за несколько минут зарегистрироваться, создать проект и добавить первую задачу в TaskTracker.

    1. Регистрация и вход

    1. Откройте URL вашего экземпляра TaskTracker (например, https://tasks.example.com).
    2. Нажмите «Регистрация», укажите рабочий e-mail и надёжный пароль.
    3. Подтвердите адрес по ссылке из письма и войдите в систему.

    Корпоративный вход

    Если у организации включён SSO (SAML или OpenID Connect), на странице входа будет кнопка «Войти через организацию» — используйте её вместо пароля.

    2. Создание организации и проекта

    После первого входа мастер предложит:

    1. Название организации — например, «ООО Альфа».
    2. Идентификатор проекта (ключ) — короткий префикс для номеров задач, например ALF. Задачи получат номера вида ALF-1, ALF-2.

    Пример заполнения полей в интерфейсе:

    Название организации: ООО Альфа
Ключ проекта: ALF
Название проекта: Веб-сайт

    Ключ проекта

    Ключ обычно пишут латиницей заглавными буквами, 2–10 символов. Его сложно изменить позже — выбирайте осмысленно.

    3. Первая задача

    1. Откройте проект «Веб-сайт».
    2. Нажмите «Новая задача» или кнопку «+» на доске.
    3. Заполните поля:
    4. Заголовок — кратко, по сути работы.
    5. Описание — можно использовать Markdown (списки, ссылки, код).
    6. Исполнитель — выберите себя или коллегу из списка.
    7. Срок — опционально.

    Пример описания в Markdown:

    ## Цель
Сверстать главную страницу по макету Figma.

## Критерии готовности
- [ ] Адаптив 320–1920 px
- [ ] Проходит Lighthouse Performance > 90

Ссылка на макет: [Figma](https://www.figma.com/file/...)

    4. Перемещение по доске

    Колонки (например, «К выполнению», «В работе», «Готово») отражают этапы workflow. Перетащите карточку задачи мышью или откройте задачу и смените Статус в боковой панели.

    Права доступа

    Перемещение в некоторые колонки может быть ограничено ролью. Если кнопка неактивна, обратитесь к администратору проекта.

    5. Приглашение команды

    1. Настройки организации → Участники → Пригласить по e-mail.
    2. Укажите адрес и роль: Участник или Наблюдатель.
    3. После принятия приглашения коллеги появятся в списке исполнителей.
